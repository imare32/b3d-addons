# 生成式 Girih 星形纹样（Gen Girih）

阿基米德镶嵌上的 **girih** 星形纹样生成器 + Blender 扩展（扩展 id `gen_girih`，Blender 5.2.2
实测）：选一种正多边形镶嵌、给一个接触角，得到一张**真正的编织**——长股线在交叉点上一上一下，
压下的那一段真切掉缺口、缺口用一块沿对方边缘裁齐的补片贴平，底下一圈更宽的描边始终不断。

几何移植自 [`islamic-patterns`](https://github.com/evoluteur/islamic-patterns) 的 `js/girih.js`
（MIT），逐函数对数量；切口、补片与 Grease Pencil 后端沿用 [`gen_zellij`](../gen_zellij/README.md)
里实测过的做法。

## 快速开始

1. 仓库已注册为本地扩展仓库（见根目录 `README.md`），在偏好设置里启用 **Gen Girih**；
2. 3D 视图侧栏出现 **Girih** 面板（F3 里也有 `gen_girih.*` 算子）；
3. 选镶嵌 → 点「生成」，默认就是「交织」样式（一上一下的蕾丝边）；
4. 拖「接触角」：图案会自己跟着变（停手 0.25 s 自动重建）；
5. 要直接出图点「场景预设」：2048×2048 正交相机、Standard 色彩、GP 抗锯齿 16、世界背景铺
   面板上的画布底色，并把视图背景从「主题」切成「世界」。

算子：`gen_girih.generate`、`gen_girih.sweep`、`gen_girih.delete`、
`gen_girih.sync_from_object`、`gen_girih.setup_scene`。

**就地生效**（不重建几何）：配色、画布底色、两个颜色、不透明度、图层显隐；线条 / 带子样式下
线宽与描边倍数也只是重写 `radius`。

**必须重新生成**：镶嵌、接触角、间隙、边长、画布、样式、缝隙、填充相关、砖轮廓，以及
**交织样式下的线宽与描边倍数**——缺口是按可见半宽切出来的，宽度一变刀口位置就变了。面板会
提示「交织样式：线宽 / 描边改了要重新生成」。

## 图层语义

| 图层 | 内容 | 默认 |
|---|---|---|
| `Fills` | 每块砖星形轮廓的填充（可选，按边数分色时一砖一色） | 关 |
| `Lines` | 线条样式下的单层笔划 | 视样式 |
| `Case` | 描边层：**整根股线不切**，露出来的一圈就是蕾丝边 | 显示 |
| `Band` | 本体：切过缺口的段 + 只填不描的端头补片 | 显示 |
| `Tiling` | 砖轮廓调试层（跟随描边色） | 关 |

`Case` 与 `Band` 相对顺序固定（描边在下），否则补片盖不住描边的内缘。

## 算法

### 1. 镶嵌与射线（`girih.py`，纯 Python，不 import bpy）

1. `TILINGS`：十种镶嵌，每种 = 两个**格矢** + 一个格胞里的若干 `[中心x, 中心y, 边数, 起始角°]`，
   边长恒为 1；
2. `motif_and_star()`：每条边的中点按**接触角**向砖内发两条射线，各自停在相邻角的**角平分线**上
   ——与角平分线求交而不是射线与射线求交，极端角度下相邻射线近乎平行，与角平分线求交永远有解；
3. `gap` 把一条边的两个出发点沿边各推开 `gap × 边长 / 2`，两条射线于是在边内交叉，得到双线；
4. 同一次计算顺手给出**星形轮廓**（`[边上的交叉点, 角点]` 交替的 2n 边形），它正好被股线围住，
   填充它就是给星心铺底。

### 2. 股线与交叉（`girih.weave`）

段去重 → 结点按「最接近反向」配对 → 追股线 → 在 4 价结点记交叉（带夹角正弦与两条股线各自的
弧长位置）。

**股线极少极长**：`4.8.8` 整张图是**一条** 1808 点的闭合股线，`4.6.12` 是 5 条。所以「描边层 =
整根股线」只有个位数笔划。

### 3. 一上一下（`girih.over_under`）

规则只有一条：**同一根股线上相邻的两次经过必须一上一下**，写成异或方程后沿约束图 BFS：

```text
over(第 k 次经过) = 该股线相位 XOR (k & 1)
相位[b] = 相位[a] XOR 1 XOR (序号_a & 1) XOR (序号_b & 1)
```

自交 / 奇环理论上可能无解，遇到就从下一个未定的交叉重新播种，并把「没能严格交替」的处数记进
面板读数。实测十种镶嵌 × 10°–80° × 间隙 0–0.4 **全为 0**。

### 4. 切口与补片（`interlace.py`）

- 切口 `d = reach / tan(θ/2)`（`reach = max(线宽, 描边半径)`）：90° 时 `d = reach`，切口正好压在
  对方边缘线上；角度越斜退得越远（56° → `1.87×reach`）；
- 端头补片 = 本体局部矩形被「对方边缘」那条半平面裁一刀，外缘因此**平行于对方边缘**，贴平与
  遮挡同时成立；补片只填不描，与本体同色；
- 切段按弧长做，**闭合股线跨接缝的刀折成两段**、**首尾两段合并成一条路径**——否则接缝处两个
  平头端帽之间会张开一个黑色小扇形；
- 短于 `2×reach` 的残段不丢弃，而是**撤掉造出它的那一刀**（收刀），带子连续穿过去；
- 接近 90° 的交叉补片本来就窄到没意义：这时**照切、不补**（端头已经平齐对方边缘）。这与
  「补不出来」是两回事，混为一谈会让接触角一到 45° 附近整张图失去编织。

## 数据与性能

默认 `4.6.12` / 62° / 边长 0.64 / 画布 10（Blender 5.2.2 实测）：

| 指标 | 值 |
|---|---|
| 砖 / 段 / 股线 | 121 / 1512 / 5 |
| 交叉 / 切口 / 补片 / 本体段 | 328 / 328 / 656 / 328 |
| 形状数 | **994**（`Case` 5 根整股线 + `Band` 989 = 333 段 + 656 补片） |
| 本体层点数 | 4464（含补片） |
| 生成耗时 | **33 ms** |

最密的三角形镶嵌（1180 交叉、3564 形状）约 83 ms。开填充 +121 个多边形，约 67 ms。

**密度上限**：`画布 / 单元边长 ≤ 64`。砖数按面积涨，再密就是四倍耗时，超限会直接报错并提示
调大「单元边长」。

## 已知限制

- **画布 = 取景框**：图案是无限的，生成时向外多要一圈砖（画布外还有一圈"毛边"）。「场景预设」
  按**画布**取景，所以正常出图看不到它；把相机移出去会看到那圈砖不齐的残边；
- **`双线间隙 > 0` 会把股线拆碎**（参考实现的行为）：股线从 5 条变成几百条小环，切口又密，
  会有相当一部分交叉退化为「不编」（收刀）。面板在收刀超过 10% 时提示；想要完整编织就用 0；
- **交织样式下线宽与描边是几何参数**：缺口按可见半宽切，改它们必须重新生成；
- **描边倍数 = 1.0 时编织读不出来**：没有那圈描边，就看不出谁压谁。1.3–1.4 是细蕾丝边，
  想一眼看出编织感可以提到 1.6–1.7；
- **扫掠吃内存**：每帧一份完整几何，24 帧 × 4464 点约几 MB；240 帧要先算一下。
